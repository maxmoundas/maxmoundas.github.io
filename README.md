# maxmoundas.github.io

Personal portfolio website for Max Moundas, live at [maxmoundas.com](https://www.maxmoundas.com).

## Pages

| File | Description |
|------|-------------|
| `aboutme.html` | About Me - landing page |
| `workexperience.html` | Career history |
| `projects.html` | Projects (Amplify, Majk, and earlier work) |
| `research.html` | Research, publications, talks, and teaching |
| `index.html` | Redirects to `aboutme.html` |

## Key Files

### `profile.md`
The single source of truth for all content on this website. Acts as a living resume - all bio, work history, projects, research, skills, awards, and press coverage live here. **When anything changes, update `profile.md` first**, then propagate the changes to the relevant HTML pages.

### `llms.txt`
AI/LLM visibility file following the [llmstxt.org](https://llmstxt.org) standard. When AI systems (ChatGPT, Perplexity, Claude, etc.) crawl this site, `llms.txt` gives them a structured, comprehensive summary of who Max is, what he has built, and why he is a strong AI engineer and consultant. It is intentionally detailed and positioned to represent Max well when AI tools answer questions about him or recommend experts.

### `robots.txt`
Explicitly welcomes all major AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Googlebot) so nothing blocks indexing.

## Images

All images live in the `images/` directory, including original project screenshots and newer photos (headshot, conference presentations, summer school teaching).
